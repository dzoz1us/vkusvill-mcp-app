# Edimo — Планировщик питания

Персональный план питания с интеграцией ВкусВилл.

## Структура проекта

```
edimo/
├── frontend/   # React + TypeScript + Vite
└── backend/    # FastAPI (Python) — в разработке
```

## Технологии

### Frontend

- **TypeScript** — строгая типизация
- **React 18** — UI библиотека
- **Vite** — сборщик
- **React Router** — маршрутизация
- **Zustand** — управление состоянием
- **Tailwind CSS** — стилизация

## Запуск Frontend

```bash
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173

## Сборка для продакшена

```bash
cd frontend
npm run build
```

Готовые файлы будут в папке `dist/`.

## Функционал

### 1. Онбординг

- Выбор количества человек (1-10)
- Выбор дней недели для планирования
- Установка бюджета
- Предпочтения (быстро, низкокалорийно, семейное и т.д.)
- Тип диеты (без ограничений, вегетарианство, веганство, пескетарианство)
- Кухонная техника (плита, духовка, мультиварка и т.д.)

### 2. План питания

- Отображение рецептов на каждый день (завтрак, обед, ужин)
- Прогресс-бар бюджета
- Замена блюд
- КБЖУ для каждого рецепта

### 3. Детали рецепта

- Ингредиенты с количеством
- Пошаговое приготовление
- Пищевая ценность

### 4. Список покупок

- Группированный список товаров
- Статус подбора (найден, требует проверки, не найден)
- Чекбокс "Куплено"
- Расчёт стоимости

### 5. Корзина ВкусВилл

- Создание ссылок на корзину
- Обработка лимита 20 товаров
- Предупреждения об изменении цен

## API Endpoints

- `POST /api/meal-plans/generate` — создание плана
- `GET /api/meal-plans/{id}` — получение плана
- `GET /api/recipes/{id}` — детали рецепта
- `POST /api/meal-plans/{id}/replace-meal` — замена блюда
- `GET /api/meal-plans/{id}/grocery-list` — список покупок
- `PATCH /api/grocery-items/{id}` — обновление статуса покупки
- `POST /api/meal-plans/{id}/vkusvill-cart` — создание корзины

## Разработка

Проект следует принципам:

- React никогда не вызывает MCP напрямую (только через Backend)
- Строгая типизация TypeScript
- Обработка состояний: idle, loading, success, empty, error
- UX-правила для отображения ориентировочных цен
